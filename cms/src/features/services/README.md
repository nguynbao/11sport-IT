# Feature Dịch vụ Kỹ thuật (`services/`)

Quản lý danh mục loại dịch vụ (căng vợt, sửa chữa...) và đơn dịch vụ từ tiếp nhận tới thu tiền/trả đồ.

## Cấu trúc
- `hooks/useServiceManagement.ts`: State, bộ lọc và các thao tác cập nhật trạng thái/thanh toán đơn dịch vụ.
- `components/`: `ServiceManagementModule.tsx`, `ServiceOrdersTab.tsx`, `ServiceTypesTab.tsx`, `ServicePaymentModal.tsx`, `ServiceEditModal.tsx`.
