# Feature Đơn nghỉ phép & WFH (`leave/`)

Tạo, theo dõi, hủy và duyệt đơn xin nghỉ phép, nghỉ không lương, WFH, đi trễ/về sớm và đổi ngày OFF.

## Cấu trúc
- `api.ts`: API danh sách đơn, tạo đơn, hủy đơn và duyệt/từ chối đơn.
- `components/LeaveRequests.tsx`: Export `CreateLeaveModal`, `MyLeaveRequestsPanel` và hằng số `LEAVE_REASON_MAX`.
