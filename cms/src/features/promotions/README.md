# Feature Khuyến mãi (`promotions/`)

Quản lý chương trình khuyến mãi (giảm %, giảm tiền, tặng kèm theo đơn/danh mục/sản phẩm) và trạng thái chạy.

## Cấu trúc
- `hooks/usePromotionModule.tsx`: State, bộ lọc và xử lý tạo/sửa/tạm dừng/xóa khuyến mãi.
- `components/`: `PromotionModule.tsx`, `PromotionFormModal.tsx`.
