# Feature Đơn hàng, Trả/Đổi & Công nợ (`orders/`)

Tra cứu hóa đơn POS, bản nháp, lịch sử phiếu trả/đổi hàng và theo dõi/thu hồi công nợ khách hàng.

## Cấu trúc
- `exports.ts`: Xuất Excel danh sách đơn hàng và phiếu trả/đổi hàng.
- `components/`: `OrdersReturnsModule.tsx`, `DebtManagementModule.tsx`.
